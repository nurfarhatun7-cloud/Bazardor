# 🛒 বাজার দর (BazarDor)

বাজার দর is a Bengali web app that shows the daily prices of essential grocery items such as rice, lentils, oil, vegetables, fish, meat, eggs, dairy and spices, with price changes and market-wise details.

## Live Link

https://bazardor-gamma-smoky.vercel.app
## Technologies Used

- Next.js (App Router)
- TypeScript
- Tailwind CSS and DaisyUI
- BetterAuth
- MongoDB Atlas
- react-hot-toast
- Vercel

## Features

1. Live scrolling price ticker with price change percentages.
2. Top 6 risers and top 6 fallers of the day.
3. All products grid, responsive on mobile, tablet and desktop.
4. Category pages with numeric sorting, skeleton loading and an empty state.
5. Protected product details page with min, max, average and market-wise prices.
6. Sign up and sign in with BetterAuth and toast messages.
7. My Profile page with an update-name feature.
8. Custom 404 page.
